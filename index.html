Mission Briefing

Your goal is to successfully launch the rocket to orbit (Line 10). The flight software contains 4 critical bugs. Debug the program using the dropdown menus.

  • Syntax Error: A typo the computer cannot parse.
  • Resource Semantic Error: Valid code that drains all fuel before orbit.
  • Logic Error: A bad decision that destroys the ship aerodynamically.
  • Context Semantic Error: A command that works on Earth but fails in the vacuum of space.

Compare how the Interpreter (translating live mid-flight) and the Compiler (pre-building the whole program upfront) handle these errors differently. Note: Switching engines will reset the bugs.
