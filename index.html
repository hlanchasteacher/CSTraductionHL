Task Instructions:

You must program the rover to reach the green flag (Line 10). There are 4 hidden bugs in the code. Your goal is to debug the program using both the Interpreter and the Compiler translation engines.

  • Syntax Error: A grammar mistake/typo. (Compilers catch these immediately during build).
  • Semantic Error: Grammatically correct, but causes a critical fault in context (e.g., running out of battery, hitting a low ceiling).
  • Logic Error: Valid code that simply executes the wrong plan (e.g., turning into a wall).

Notice how the Interpreter crashes instantly but forces you to restart constantly, while the Compiler takes a long time to build upfront but runs the hardware smoothly once ready!
